# 提示词指南（Qwen-Image 3.0 @ Qwen Studio）

## 0. 环境事实：先读这段

- 网页端**没有提示词扩写开关，也没有反向提示词输入框**（2026-09-19 实测）。所以要什么细节必须自己写进提示词；想避免的东西只能用**正向约束句**表达（示例：写"背景是干净的白墙"而不是"背景不要杂物"）。
- 长度：目标 **120–400 字**。API 侧上限 2100 字符（网页端实测未见截断），不必堆砌。
- **信息密度 3–5 个关键要点最优**（官方结论）。堆到十几个互不相干的词，模型会左右摇摆、画质下降。

## 1. 两套公式

### A. 视觉类（人像 / 动物 / 风景 / 产品）——官方五要素 + 主体

```
主体（谁 + 关键外貌）→ 景别 → 视角 → 镜头 → 光线 → 风格 → 画质质感
```

| 要素 | 可选值 |
| --- | --- |
| 景别 | 特写 / 半身 / 全身 / 远景 |
| 视角 | 平视 / 俯拍 / 仰拍 / 过肩 |
| 镜头 | 85mm 定焦 / 35mm 纪实 / 广角 / 微距 / 长焦压缩 |
| 光线 | 柔和窗光 / 逆光轮廓 / 黄金时刻 / 阴天散射 / 霓虹反射 / 顶光硬阴影 |
| 风格 | **只写一个**：写实摄影 / 日系动画 / 水墨 / 赛博朋克 / 商业产品摄影 / 吉卜力风 |

### B. 信息类（海报 / 信息图 / 分镜 / UI / 课件）——3.0 创意简报七段

3.0 的看家本领是**文字与版面**，这类需求别用"美图思维"，按简报写：

1. **成品**：一句话说清是什么（"中文产品对比信息图，用于落地页"）
2. **画布**：比例 + 版式（"16:9，三栏布局"）
3. **层级**：标题 / 分区 / 侧栏 / 表格 / 图例，各放哪
4. **引号文案 + 语言**：必读文字用引号写死，并明说语言（"标题用中文：'三分钟看懂'"）
5. **视觉系统**：配色 / 字体方向 / 光线 / 材质 / 风格
6. **约束**：必须清晰、必须保留、必须留白的部分
7. **审校**：生成后人工核对拼写、数字、品牌名

> 官方建议：**先生成结构，再分轮精修**文案与质感，不要一次改动所有变量。

## 2. 三档填空模板

**① 最小可用（≥120 字，弱模型兜底）**
```
<景别><主体与外貌>，<服装/状态>，<场景>，<光线>，<一个风格标签>，<质感细节>
```

**② 标准（250–400 字）**
```
<风格><景别>：<主体 + 年龄 + 外貌特征>，<服装与配饰>，<动作与表情>，
<场景 + 道具>，<光线（方向 + 质感）>，<色彩基调>，<镜头与景深>，
<材质/颗粒等质感>，<画面占比与留白>
```

**③ 信息型（按七段填）**
```
一段：为<用途>做一张<比例>的<成品类型>。
版式：<分栏/分区>。
层级：标题在最上方；中部<...>；底部<...>。
文案：「<中文文案>」用<字体方向>；标签用<语言>。
视觉：<配色>，<光线>，<风格>。
约束：文字必须清晰水平；<某区域>留白。
```

## 3. 反例表（弱模型最容易犯的六种）

| 错法 | 为什么错 | 改法 |
| --- | --- | --- |
| 堆"8K、杰作、大师作品、超高清" | 空洞权重词不提供信息 | 换成**具体**的光线、材质、镜头 |
| 写两个风格标签（"赛博朋克 + 吉卜力"） | 模型在两套风格间摇摆 | 只留一个 |
| "一个女生"就提交 | 抽象 → 出图随机 | 补年龄 / 发型 / 服装 / 表情 |
| 描述复杂手部动作 | 手部畸变高发区 | 改成静态姿势或简化手部 |
| 用"不要 XX"表达排斥 | 无反提示词入口，否定词易被忽略 | 改写成正向肯定 |
| 信息型一次塞满所有细节 | 结构崩、文字乱 | 先出骨架，再分轮精修 |

## 4. 配方库（8 类）

**写实人像** 3:4 — 电影感半身人像：一位二十五岁左右的东亚年轻女性，黑色长发自然垂落，米白色针织毛衣，坐在洒满清晨阳光的窗边，柔和逆光勾勒发丝边缘，浅景深，细微胶片颗粒，暖奶油色调，85mm 定焦，写实摄影

**二次元立绘** 3:4 / 9:16 — 日系动画半身立绘：银灰渐变双马尾少女，琥珀色大眼，白色水手服配深蓝领结，樱花纷飞的校园走廊，午后金光透过枝叶洒下单片光斑，柔和赛璐璐上色，干净线稿，发丝高光细腻

**街头时尚** 3:4 — 街头时尚全身照：二十岁出头东亚女生，齐肩短发挑染浅棕，oversize 黑皮夹克 + 格纹百褶裙 + 厚底马丁靴，夜晚霓虹灯牌下的湿漉街头，地面反射粉蓝霓虹，35mm 纪实风格

**风景建筑** 16:9 — 清晨薄雾中的江南水乡，青石板拱桥与白墙黛瓦倒映在静谧河面，乌篷船缓缓划过，晨光穿透薄雾形成可见光束，清透水墨意境融合现代摄影质感，青灰色调

**产品商业** 1:1 — 极简产品摄影：哑光白色陶瓷咖啡杯置于浅灰 linen 桌布，右侧留白，柔和顶光与长投影，莫兰迪色系，商业质感

**信息型海报** 16:9 — 为新品发布做一张 16:9 中文海报：左侧 1/3 放主标题「慢烘七日」，下方一行副标题「浅烘单品豆」；右侧放咖啡豆俯拍特写；米白与深棕配色，留白充足，字体方向为现代无衬线中文；所有文字水平清晰

**分镜多格** 9:16 — 竖版 4 格连续分镜，讲"女孩雨天等公交"：第 1 格远景站台；第 2 格中景撑伞侧脸；第 3 格特写雨滴打在伞面；第 4 格公交进站暖光。统一日系动画风格，角色服装与发型在四格中保持一致

**UI / 界面概念** 9:16 — 手机 App 深色模式主界面概念图：顶部标题「今日概览」，中部两张数据卡片，底部四个图标导航；深灰蓝配色，圆角卡片，柔和阴影，现代极简 UI 风格，界面文字清晰

## 5. 提交前自检（5 秒过一遍）

1. 五要素齐了吗（主体 / 景别 / 光线 / 风格 / 质感）？
2. 风格标签是否只有一个？
3. 有没有**具体**的光线与材质描写？
4. 信息型需求写了引号文案 + 语言吗？
5. 关键要点是否 ≤5 个，没有互相打架？
